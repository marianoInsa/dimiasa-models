# DiMIASA

Proyecto de investigación sobre modelos inteligentes aplicados a salud y ambiente, desarrollado en CInApTIC — UTN Facultad Regional Resistencia.

Esta carpeta contiene notebooks, scripts y firmware para analizar señales de caídas, ECG y PPG. La descripción para nuevos lectores, la guía de uso y los resultados están centralizados en la [documentación del proyecto](doc/README.md).
